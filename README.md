# Wildlife Music Studio

A creative studio for producing children's music videos featuring realistic wildlife scenes.

## Current Project

**Ten Animals, Ten Words**

A children's educational song introducing ten animal names in English.

## Features

- Audio playback.
- Upload and preview audio files.
- 10 editable cinematic animal scene prompts.
- Lyrics editor.
- Export project settings as JSON.
- Mobile-friendly interface.

## Visual Style

Realistic cinematic wildlife documentary.

## Project Structure

- `public/index.html` — Main interface.
- `public/styles.css` — Website design.
- `public/app.js` — Studio functionality.
- `assets/assets/` — Audio files.

## Important Note

This project currently organizes production materials and exports JSON files. It does not generate or render the final video yet.
